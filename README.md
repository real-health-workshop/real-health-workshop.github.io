A workshop proposed for NAACL 2027 (San Francisco, June 1-5, 2027).
Web URL: https://real-health-workshop.github.io/
Proposal submitted to the ACL joint call for workshops, September 4, 2026. Notification October 2, 2026.

Built with Jekyll and the al-folio theme, hosted on GitHub Pages.

NOTE ON THE REPOSITORY NAME. The `url` in `_config.yml` is set to
https://real-health-workshop.github.io, which matches the URL given in the
submitted proposal. For that URL to resolve, this repository must be named
`real-health-workshop.github.io` under a GitHub user or organization called
`real-health-workshop`. If you keep the existing repository instead, change the
`url` line in `_config.yml` back and update the URL in the proposal PDF to match.
